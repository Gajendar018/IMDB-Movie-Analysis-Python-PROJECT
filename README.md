# MDB-Movie-Analysis-Python-PROJECT
“A data analysis project exploring IMDB movie trends using Python, Pandas, Matplotlib, Seaborn, and Jupyter Notebook.”

##IMDB Movie Analysis 

An end-to-end data analysis project using Python, Pandas, Matplotlib, and Seaborn.
This project explores movie ratings, budgets, revenue patterns, genre trends, and decade-based observations using an IMDB dataset.

Genre & Decade Insights

Rating Trends Over Years

Budget vs Revenue Correlation

Visualizations with Matplotlib & Seaborn

## 📊 Major Insights

Most movies are rated between 6–8, showing stable overall quality

Drama & Documentary have the highest average ratings

Action, Adventure & Sci-Fi popularity increases after 2000s

Budget strongly predicts revenue, not ratings

Movie production significantly increased after 2010

Audience preference shifted towards VFX-heavy visual genres

## 📝 Conclusion

This project gives a clear understanding of:

How movie trends evolved

How genres rise/fall over decades

How budget impacts success

How audience preferences shift over time
